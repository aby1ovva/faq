# 🚀 Простая инструкция по запуску

## Что у вас должно быть:

✅ Backend запущен (mvn spring-boot:run)  
✅ В FAQController.java есть @CrossOrigin(origins = "*")  
✅ 3 файла frontend: index.html, style.css, app.js

---

## Шаги запуска:

### ШАГ 1: Проверьте Backend

1. Откройте браузер
2. Перейдите: http://localhost:8080/api/faqs
3. Должен показать JSON с данными

**Если НЕ показывает** - запустите backend:
```bash
cd faq-backend
mvn spring-boot:run
```

---

### ШАГ 2: Откройте Frontend

**ВАРИАНТ А (рекомендуется):**

1. Установите в VS Code расширение **Live Server**
   - Ctrl + Shift + X
   - Найдите "Live Server"
   - Нажмите Install

2. Правой кнопкой на `index.html`
3. Выберите **"Open with Live Server"**
4. Браузер откроется автоматически

**ВАРИАНТ Б (простой):**

1. Найдите файл `index.html` в проводнике
2. Двойной клик - откроется в браузере

⚠️ Если ВАРИАНТ Б не работает - используйте Live Server!

---

### ШАГ 3: Проверьте работу

Должно появиться:
- ✅ Индикатор загрузки (спиннер)
- ✅ Список вопросов из базы данных
- ✅ Форма добавления справа
- ✅ Поиск работает
- ✅ Фильтры работают

---

## Если что-то не работает:

### 1. Открываем DevTools (F12)

Нажмите `F12` в браузере → вкладка **Console**

### 2. Смотрим ошибки:

**Ошибка: "CORS"**
→ Проверьте, что в FAQController.java есть @CrossOrigin(origins = "*")
→ Перезапустите backend

**Ошибка: "Failed to fetch" или "Network error"**
→ Backend не запущен
→ Запустите: mvn spring-boot:run

**Ошибка: "404 Not Found"**
→ Проверьте URL в app.js (должно быть http://localhost:8080/api/faqs)
→ Проверьте, что backend работает

**Пустая страница**
→ Откройте Console (F12)
→ Посмотрите какая ошибка
→ Напишите мне эту ошибку
